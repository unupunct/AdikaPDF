# Adika PDF Editor

Privacy-first, offline Windows PDF editor (read, comment, edit, sign, organise, protect, OCR, convert). Version 1.12.0. MIT. Repo: https://github.com/unupunct/AdikaPDF (branch `main`).

## Architecture
- **Tauri 2 desktop app.** Almost all logic runs in the WebView (React 18 + TypeScript + Vite 7 + Tailwind 4, state in zustand, canvas via Konva, rendering via pdf.js, writing via pdf-lib).
- **Rust side (`src-tauri/src/`)** is thin: file I/O with raw IPC bodies (`lib.rs`), Windows certificate store listing and CNG/CryptoAPI signing (`certstore.rs`; E2E imports a throwaway .pfx in memory via `ADIKA_WINSTORE_TEST_PFX`), app cache files (`appdata.rs`, `%LOCALAPPDATA%\Adika PDF Editor\Data` or `ADIKA_DATA_DIR`), Office/HTML/WIA conversion (`convert.rs`), HTTP + Windows cert store for OCSP/CRL/timestamps (`net.rs`), PKCS#11 token signing (`pkcs11.rs`), logs and crash reports (`logging.rs`), and the virtual-printer watcher (`print_watcher.rs`, started with a special CLI flag, no window).
- Single-instance plugin: a second launch forwards PDF paths to the running window (`adika://open-files` event).
- Installer: NSIS (`src-tauri/windows/hooks.nsh`, `printer.ps1` creates the "Adika PDF Editor" printer on top of Microsoft Print To PDF and enables the Print Spooler).

## Layout
- `src/actions/`: user-facing operations (convert, document, print, quickTools, security, sign)
- `src/components/`: ribbon, modals, sidebar, viewer, shell, inspector, ui primitives
- `src/lib/pdf/`: format engines (convert, exportPdf, exportFormats, pdfa, ocr, compress, repair, xps, dxf, epub, email, annotations)
- PDF -> Word/ODT/RTF/Markdown/Excel/CSV/EPUB share one page-layout analysis: `wordLayout.ts` (pure: paragraphs, alignment, lists, ruled/aligned tables, columns, image placement, running headers/footers), `docx.ts` (reads images/rules/colours from pdf.js via `collectDocxGraphics`, `planDocument`, writes .docx in flowing or exact mode), `docWriters.ts` (ODT, RTF, Markdown, rows, reflow blocks).
- Text engine `src/lib/pdf/textRemoval.ts`: interprets page content streams (glyphs with Unicode and exact boxes), deletes letters inside areas, writes replacement text in the document's own font and reflows the line. Used by redaction (vector first, raster fallback when images/drawings/forms/unmeasurable fonts are under a box), Find & replace (`actions/findReplace.ts`, rebuilds the source immediately, undoable) and Edit text. `textSearch.ts` finds matches on it; `lib/patterns.ts` has the redaction patterns (IBAN mod 97, CNP, Luhn).
- Saving drops unreferenced objects (`lib/pdf/prune.ts`): otherwise a redacted page's original stream stays in the file.
- `lib/formDetect.ts` (Detect fields, on the rendered page), `lib/batch.ts` + `actions/batch.ts` (Batch), `lib/updates.ts` (opt-in GitHub release check; version from package.json via `__APP_VERSION__`).
- Interface language: `lib/i18n.ts` translates the DOM at runtime from `src/locales/ro.json` + `ro.extra.ts` (English string -> Romanian; `{0}` patterns, plural `{0#one|few|many}`). New UI strings need a Romanian entry: `tests/i18nCoverage.test.ts` fails otherwise and `node scripts/i18n-extract.cjs . out.json` lists them. Mark user/document content with `data-no-translate`. E2E pins English at start.
- `src/lib/crypto/`: `digitalSignature.ts` (signing and verification: classic or PAdES baseline B-B/B-T/B-LT/B-LTA, document timestamps, DSS/LTV, certification, QcStatements), `euTrustedList.ts` (EU LOTL + national trusted lists parsed into CA/QC and TSA/QTST trust anchors), `encrypt.ts` (AES-256)
- Other round-8 engines: `src/lib/mailMerge.ts` (CSV/XLSX reader, form fill per row), `src/lib/batch.ts` (batch ops and action sequences), `src/lib/pdf/accessibility.ts` (checker + auto-tagger), `editableScan.ts` (OCR text as visible text), `visualCompare.ts` (pixel diff report)
- Round 9: `src/lib/scan/` (cleanup: deskew, orientation, specks, edges, blank pages; `ccitt.ts` Group 4 encoder; `scanPdf.ts` PDF building, separator sheets, splitting) with `src-tauri/src/scanner.rs` (WIA without the dialog, feeder batches); `src/lib/barcode/` (Code 128 encode + read, QR encode — tests decode with the jsqr dev dependency); `src/lib/print/` (generic CMYK model + generated ICC output profile, colour conversion of content streams / images / shadings, PDF/X preflight + conversion, bleed and printer marks, ink coverage); `src/lib/cli.ts` + `actions/automation.ts` (`--batch` command line: no window, console output via `automation.rs`, exit codes; watched folders); `src/lib/searchIndex.ts` + `actions/folderSearch.ts` (folder search index in app data); `src/lib/pdf/review.ts` (review-state replies, merging reviewers' copies); `src/lib/crypto/pubsec.ts` (certificate encryption Adobe.PubSec / adbe.pkcs7.s5; Windows-store decryption in `certstore.rs`)
- Round 10:
  - Forms: `actions/formFill.ts` (one fill path for the side panel and `viewer/FormFillLayer.tsx` on the page); `lib/pdf/formSandbox.ts` runs Acrobat form JavaScript in pdf.js' QuickJS sandbox (`pdf.sandbox.mjs` + `wasm/quickjs-eval.*`); `store/formView.ts` holds script-formatted values.
  - XFA: `lib/pdf/xfa.ts` (packets, static-XFA datasets kept in step on save; note pdf-lib's `getForm()` deletes XFA, so `buildPdf` reads the packets first and restores them last); dynamic XFA is laid out by pdf.js (`enableXfa`), measured offscreen (`xfaMeasure.ts`), built into an AcroForm PDF (`xfaPdf.ts`); `actions/xfaForms.ts` saves filled values back into the original.
  - `lib/xml.ts`: small XML DOM (parse / serialize) used by XFA, e-invoices and XMP.
  - Spell check: `src-tauri/src/spellcheck.rs` (Windows ISpellChecker via raw COM vtables), `lib/spell.ts`, `SpellCheckModal`.
  - E-invoices: `lib/einvoice/` (UBL / CII parse + checks, readable PDF, Factur-X PDF/A-3 with extra XMP via `pdfa.ts` `extraXmp`); `lib/pdf/portfolio.ts`, `tocPage.ts`.
  - Editing: `lib/pdf/vectorEdit.ts` (paths on a page; `VectorObject`), restyled text (`TextObject.original`, `LineEdit.color/sizeRatio` in `textRemoval.ts`), `lib/pdf/layers.ts` (+ `BaseObject.layer`), `pageSize.ts`, `xmp.ts`; `actions/sourceRewrite.ts` swaps in a rewritten source (undoable).
  - Windows: `src-tauri/src/shellops.rs` (launch requests `--combine` / `--convert` forwarded as `adika://launch`, Simple MAPI e-mail, second windows `open_document_window` with `?adopt=` snapshots from `lib/recovery.ts`); Explorer menu verbs in `windows/hooks.nsh`; thumbnail DLL crate `src-tauri/thumbs` (IThumbnailProvider with Windows.Data.Pdf, built by `npm run build:thumbs` before `tauri build`, registered with regsvr32); `store/customize.ts` + `shell/CustomizeModal.tsx` (Quick Access, shortcuts); pen pressure (`PenObject.pressures`).
  - Reports: redline pages in `compare.ts`, `lib/crypto/validationReport.ts`, `lib/scan/rasterRules.ts` (table lines in scans for Word/Excel export), `lib/pdf/structTree.ts` + `sidebar/TagsPanel.tsx`.
  - E2E files that import app modules directly must avoid `@/` imports (Node has no alias); `editing3.part.mjs` copies `vectorEdit.ts` into the git-ignored `.tools/` for that.
- Round 11 (hardening after a full review):
  - Signatures: `lib/crypto/pdfRevisions.ts` reads each revision through its xref chain (as viewers do); `classifyLaterChanges` compares those views (DSS/VRI exemption only, DocMDP levels, FieldMDP locks, ByteRange gap check). All signature checks go through one Web Crypto verifier (`verifyWithCert`; DigestInfo without NULL compared byte for byte); timestamps, OCSP/CRL and certificate purposes are verified. Attack tests in `tests/signatureAttacks.test.ts` (test PKI in `tests/helpers/sigPki.ts`).
  - Redaction: objects under a box are dropped or clipped (`redactionFate` in exportPdf), boxes drawn last; `lib/pdf/redactCleanup.ts` retargets or drops references to gone pages; textRemoval clears /ActualText, /Alt, /E of removed marked content. `lib/pdf/hiddenInfo.ts` + `HiddenInfoModal` (Remove hidden information; batch sanitize uses it).
  - Saving: `incrementalBlocker` / `buildIncrementalPdf` in exportPdf (comments, form values, bookmarks appended; automatic for signed documents, setting in `lib/saveSettings.ts`); the opened file stays the base (`primarySource`, `ExportInput.baseSourceId`); duplicated pages share their fields; recovery backs up every dirty tab; `actions/saveGuard.ts` (`saveFile`, `saveFileQuiet`) shows failed writes with a Save as… retry.
  - Comments already in the file: `lib/pdf/fileAnnots.ts` + `actions/fileComments.ts` (taken over on demand: `EditorObject.fileAnnot`, `PageRef.takenAnnots`; rewritten in place on save). Incremental save steps aside when any were taken over.
  - Long operations: `withBusy(label, (progress, signal) => …)` shows Cancel when the callback takes the signal. Form scripts run in a worker with a watchdog (`formSandbox.worker.ts`, `sandboxHost.ts`). OCR straightens sideways pages (`straighten`). `lib/pdf/predictor.ts` decodes PNG/TIFF predictors.
  - Windows: `src-tauri/src/pathguard.rs` (write/move/mkdir refuse system folders, Startup, executables), per-user print job claim in `print_watcher.rs`, Office with macros off and password-safe opening in `convert.rs`, launch requests queued until the window listens; the installer asks before closing Adika (hooks.nsh). Logs are per user.
- Round 12:
  - Updates: Tauri updater plugin (`tauri-plugin-updater`, capability `capabilities/updater.json`, main window only; `plugins.updater` in tauri.conf.json: pubkey, endpoint `releases/latest/download/latest.json`, passive NSIS). `lib/updates.ts` asks the signed feed first, falls back to the GitHub API + release page; `installUpdate` refuses while other windows are open and asks when documents are dirty (then writes recovery backups); `modals/UpdateModal.tsx`. Release: `npm run desktop:build:release` (`scripts/build-release.mjs`: key from `%USERPROFILE%\.tauri\adika-updater.key`, overlay `tauri.release.conf.json` turns on `createUpdaterArtifacts`, which fails without a key, so plain `desktop:build` stays keyless), then `npm run release:assets` (`scripts/release-assets.mjs` → `release-assets/v<v>/` with `AdikaPDF_<v>_x64-setup.exe`, `.sig`, `latest.json`).
  - Authenticode: `scripts/sign.mjs` is `bundle.windows.signCommand` and runs after `build:thumbs`; no-op unless Azure Trusted Signing or `ADIKA_SIGN_THUMBPRINT` env vars are set (README "Code signing").
  - Remote (cloud) signatures over the CSC API v2 (v1 tolerated): `lib/crypto/csc.ts` (`CscClient` with injectable transport / authorizer: info, OAuth 2.0 code + PKCE S256 with state check, refresh, credentials/list|info|authorize|sendOTP, signatures/signHash; `signer()` is an `ExternalSigner`, authorisation bound to the hash; RSASSA-PSS via `ExternalSigner.rsaPss`, verified in `verifyWithCert`), `actions/cloudSign.ts` (clients and tokens in memory), `store/cscProviders.ts` (provider settings in localStorage), `modals/CloudSignModal.tsx`; native `oauth.rs` (one-shot loopback listener on 127.0.0.1) and `net.rs` `api_request` (https only, bearer header, error bodies returned). Tests: `tests/csc.test.ts` against the mock service in `tests/helpers/cscMock.ts` (RSA, ECDSA P-256, PSS keys under a test CA).
  - Encrypted PDFs: `lib/crypto/decrypt.ts` (Standard handler RC4 / AESV2 / AESV3 R2–R6, own MD5 + RC4, objects read like repair.ts; `encryptWithSecurity` re-encrypts with the original /Encrypt + /ID[0], i.e. the same file key). `addSource` decrypts: `SourceDoc.bytes` are the decrypted copy, `SourceDoc.encryption.file` the file itself (signatures, incremental updates encrypt their new objects, recovery writes it). Store `protection` (`blockedReason(s, 'content' | 'pages' | 'comments' | 'forms' | 'print' | 'copy')`, `toolEditKind`), `actions/protection.ts` (owner password, keep/remove, unprotected copies need full rights), `shell/ProtectionBar.tsx`. Test fixtures from an independent encryptor in `tests/helpers/pdfEncryptor.ts`.
- Interface languages: `src/locales/<lang>.json` for de, fr, hu, it, es (same keys as Romanian; `tests/i18nLanguages.test.ts` requires every Romanian key in every language), plural rule per language in `lib/i18n.ts`
- The main window is created in `lib.rs` setup (config has `"create": false`): hidden for `--batch`, and in E2E mode it uses `ADIKA_WEBVIEW_DATA` as its WebView profile so tests never touch the user's settings
- `src/store/`: zustand stores (`usePDFStore.ts` is the main one, `tabs.ts`)
- `tests/*.test.ts`: vitest unit tests. `tests/manual/`: harness that converts real PDFs to .docx/.odt/.rtf/.md/.csv/.xlsx/.epub for a round-trip check in Word (`W2D_IN=a.pdf;b.pdf W2D_OUT=dir npx vitest run --config tests/manual/vitest.config.ts`). `tests/e2e/`: drives the release exe over the WebView2 debug port (`ADIKA_E2E=1`). `tests/token/`: SoftHSM2 token tests (SoftHSM lives in the git-ignored `.tools/`).
- `scripts/copy-*-assets.mjs`: copy pdf.js and Tesseract assets into `public/` on `npm install` (git-ignored).

## Commands
```
npm install
npm run desktop:dev      # dev window, hot reload
npm run desktop:build    # installer -> src-tauri/target/release/bundle/nsis/
npm test                 # unit tests
npx tauri build --no-bundle && npm run test:e2e
npm run typecheck
```
